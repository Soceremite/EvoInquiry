# EvoInquiry 1.6.0 升级实施记录

## 目标和范围

长程科研需要在适当边界停下来检查：局部改进是否减少了核心问题的不确定性，多个局部问题是否来自共同原因，以及继续、简化、转向或停止哪一种更有依据。研发阶段在本地完成实现与实测；2026-10-21 获准提交、推送、完成必要合并并发布 1.6.0 正式版。已安装插件和训练环境保持原状；以下保留研发时的接口与验收决定。

保留通用性：不规定每个项目必须跑多少实验，不把某个任务的指标、数据或模型写进共同规范。常规小问题直接回答；运行态只服务于已有长程任务。

## 职责和协作

| 所有者 | 1.6.0 的职责 | 边界 |
| --- | --- | --- |
| `research-pipeline` / 当前工作流 | 回顾原问题、证据、资源和下一步；请求既有 action brake | 不增加阶段、队列或数据库 |
| `research-guide` | 按任务和当前状态选择已有 skill | 不代替执行和评审 |
| 新增 `problem-synthesis` | 多问题是否共因、分离或改变抽象层级；给出可区分预测 | 不执行实验、不接受 claim、不强求统一解释 |
| `experiment-plan` | 声明比较块、调参批次和大里程碑的回顾边界与重访条件 | 不调度、不增发预算 |
| `experiment-bridge` | 收集每个里程碑证据后，在下一轮派发前执行检查点 | 运行/队列继续归原执行 skill |
| `dse-loop` | 在计划的调参批次回顾；改变搜索目标或边界需交回规划者 | 保留原 patience、时间、搜索边界和退出条件 |
| `research-manager` | 在已有权威记录中保存决定、反证、旧分支及重访条件 | 不复制 gate 状态，不以总结替代解锁证据 |
| `experiment-audit`、review / claim skills | 公平性漂移、既有评审及科学判断 | 反思记录不绕过任何原有 gate |

评审循环已有对 `bounded-inquiry` 的引用，因此复用该参考中的回顾规范，不为每个后端再复制一套规则。没有删除任何已有 skill；主线 88 个，Codex 89 个。

## 回顾尺度

- 比较块：汇总同一问题下的配置、种子和样例证据，决定下一次最小区分性检查。
- 调参批次：检查信息增益、重复修补和搜索空间，避免把每个参数试验都当作新发现。
- 大里程碑：回到原研究问题，比较已有解释、反证、成本和剩余资源。
- 方向边界：检查问题定义和抽象层级，保留旧方向、负结果和转向理由。
- 提前触发：局部修补反复、多个问题重叠、分支膨胀、证据冲突或公平性变化。

计数器是调度信号，不是研究质量评分。`due` 根据调用者提供的上下文返回建议的 kind / skill；工作流负责记录已处理边界，计数对应上次已处理检查点以来的工作，累计成本永不清零。无多问题时由当前工作流做普通回顾；公平性问题先审计。

## 接口和语义决定

以下选择在实现和复测前明确，来源为批准范围内的实现判断。

| ID | 决定 | 含义 / 可见接口 |
| --- | --- | --- |
| A-01 | 复用 `.iterations.jsonl` 和已有 run coordination | 无第二套状态机；ledger 保存不可变 reflection envelope |
| A-02 | 新 gate 生成独立 ID，绑定 kind、phase | 旧记录、相同秒时间戳或无关记录不能解除新 gate |
| A-03 | `KEEP_SEPARATE` 可无共因候选 | 不为填模板捏造原因；每个问题恰好一个下一步 |
| A-04 | 合并仍是待检验假设 | 需要支持引用、共同预测、反证记录、复杂度比较和区分性检查；工具只校验结构 |
| A-05 | `MERGE` / `ABSTRACTION_PIVOT` / `REPLAN` 等待规划交接 | 交接绑定项目内计划文件 SHA；文件身份不等于已完成科学评审 |
| A-06 | `DEFER` / `BLOCKED` 保留刹车 | 新的 gate-bound 反思解决 blocker 后才可继续；写总结不解锁 |
| A-07 | 普通 checkpoint 与多问题 synthesis 分离 | 普通回顾支持 CONTINUE / REPLAN / DEFER / BLOCKED / STOP，不需要虚构第二个问题 |
| A-08 | 先持久化 ledger，再更新 coordination | 同一内容重试复用同一个 reflection ID；中断后可核对并恢复 |
| A-09 | 保留原有状态优先级 | 实际执行待核对、证据变化、停止、预算、评审和 closeout 仍有效；反思不重置预算、推进 phase 或接受结果 |
| A-10 | 显式 record 需要已有 run | 独立建议仅返回内容；不为小任务创建 `.ei` 或配置 contract |
| A-11 | 发行契约升级到 schema 4 | 注册新增入口，继续解析 schema 2 / 3，冻结的 83 个 workflow 和原保护基线不变 |
| A-12 | 后续普通反思不解除有效计划绑定（来源：sweep） | 在同一 coordination 中持续保存 reflection_plan_ref；只有实际计划交接更新它 |
| A-13 | 普通回顾的 skill 字段为空，交回当前 owner | 避免向主线分发 Codex 专属 research-guide；多问题/公平性仍返回实际共有 skill |
| A-14 | 三套评审入口共用循环与恢复规范（来源：用户本轮批准） | 保留入口名、后端调用、既有 verdict/接受规则；状态年龄不能触发删档重开或重置预算 |
| A-15 | 旧海报入口仅承担兼容转发 | 不改调用参数、依赖及自动发现策略；新海报任务路由到 paper-poster-html |
| A-16 | 相邻能力按请求产出选择一个主所有者 | 区分问题界定、方法候选、方法细化、多问题合成、分析与正式裁决；组合流程复用有效子产物 |
| A-17 | 小时级试验是工程耐久与停止验证（实现判断） | 一张当前空闲 GPU、至少 3600 秒实际训练循环、无人为 sleep 凑时长；总墙钟上限 4100 秒、GPU 资源上限 4000 秒、单运行检查点预算 8 MiB，最新两个完整恢复点 |
| A-18 | 本轮长跑明确使用测试监督器与训练内有限值检查 | 不把测试夹具的保护冒称产品默认 watchdog，不增加生产调度 skill；保留阶段状态和全部退出/恢复证据 |
| A-19 | 调用示例必须匹配实际 MCP 参数（来源：sweep） | 四个 API 评审入口使用服务所要求的 prompt；离线执行真实 handler，确认评审正文实际送达。早期合并错误使用 message 的记录保留 |
| A-20 | 合并保留既有外部定时器边界（来源：sweep） | 共享循环明确禁止定时重进语义评审；external-cadence 仅用于等待外部事实，不替代 verdict。初稿遗漏及修复均记录 |
| A-21 | 保留主线旧状态的后端迁移默认值（来源：sweep） | 缺 reviewer_backend 的 pre-Copilot 状态继续使用 codex，缺 requires_external_acquittal 时保持 false；恢复不触发新任务的 auto 后端检测 |
| A-22 | 按已完成执行自动打开回顾门（来源：用户批准；接口细节为实现判断） | 新增长程任务显式固定 reflection_every_actions；成功及失败的已结算 action 计入，取消不计；旧合约默认关闭，恢复不改变原频率。触发只请求判断，不预设 CONTINUE 或转向 |
| A-23 | 停止意图与真实执行连接（来源：用户批准） | 现有本地启动器轮询绑定工作流的停止意图和按 snapshot/process 身份绑定的单执行停止请求；仅停止自己创建的进程组，保留实际退出和原因回执。普通回顾门不杀掉健康训练 |
| A-24 | 补充验收窗口与旧一小时结果分别计时（来源：实现判断） | 原窗口已终态，不延长或重置其预算；新验证窗口最多 3600 秒含模型回顾及收尾，信号齐备可提前结束；失败和未观察到的行为原样报告 |
| A-25 | 科研转向必须来自实际模型判断（来源：用户批准） | 用真实多轮训练输出、固定验证样本、反例和负结果作为输入，保留模型原始调用与决定；不硬编码回顾 verdict，不把工程保护、结构校验或单场景成功当作通用自主科研证明 |
| A-26 | 当前硬件与原记录不同（来源：实际预检） | 当前两张 RTX 5090；旧 torch 2.8.0+cu126 内核不兼容，保留失败。优先验证已有 cu128 独立环境，不改旧环境，不沿用旧 H100 环境的冻结指纹 |
| A-27 | 执行超时受原边界约束（来源：实现判断） | 本地启动器取显式 timeout、spec 的 max_seconds_per_attempt 及已配置工作流原剩余派发时间的最小值；后续停止和控制损坏可提前结束，回顾不重置时钟。硬件资源仍按已有 owner 的实际观测结算 |
| A-28 | 长单任务也需要自动回顾边界（来源：实现判断） | 可固定 reflection_interval_seconds；既有监控 owner 调用 inspect 或申请新 action 时，控制器按原起点/上次实际解决回顾的时间打开门。无需等训练结束，不在启动器内调用模型或新增后台调度器；计时只触发回顾，不决定 verdict |
| A-29 | 协作式停止也可能返回 0（来源：独立假设审查 D1） | 执行停止状态独立于实际退出码；训练收到信号、保存恢复点并以 0 退出，仍结算为 cancelled 且不进入成功实验聚合；原始退出码和终止回执保留 |

## 实现和验收

新增主线及 Codex `problem-synthesis`、一个条件加载的格式参考和 `problem_synthesis.py`。扩展现有 iteration recorder / research controller，并在上述所有者的边界接入。CLI 从实际安装包路径解析，不假设研究项目就是 toolkit 仓库。

验证包含输入校验、真实 CLI、UTF-8、旧记录隔离、BLOCKED / DEFER、规划交接、重复写入、中断恢复、原 stale ladder、预算/评审优先级、镜像/契约/打包以及合成数据上的实际前向使用。完整记录见 [validation](VALIDATION_1_6_0.md)。本地测试不冒充 native Windows/macOS CI，不把合成场景或同系列 reviewer 判断称为科研认证。

三项功能收敛已完成；补充停止实现前的全量回归为 1,331 通过、36 跳过、46 个子测试通过，
971 个实现、skill、测试及 CI 文件在冻结验证后保持一致。先前失败、未完成
尝试、两轮同系列 sweep 及修复记录均保留，不折算为全部验收通过。

小时级工程验证已完成：真实 CUDA 循环 3,600.004 秒、2,145,720 步，无人为
sleep 凑时长；三次预编程健康回顾，30 次保存后保留两个完整恢复点。NaN 注入
后实际失败退出，最新状态恢复并两次重放三步得到一致的完整状态哈希，最终
结算为 STOPPED，所属进程均退出。保护由测试训练代码与监督器提供；产品默认
统一急停链路及长程模型自主科研判断仍不在本轮已完成的验收范围内。原始终态
摘要为 `validation/v160/hourly/observed-summary.json`，详细限制见验证文档。

后续 A-22 至 A-29 的自动回顾及本地执行停止实现已完成。最终全量回归为
**1,349 通过、36 跳过、46 个子测试通过**；原时钟内约 44 分钟的补充模型观察
实际出现 REPLAN、STOP、绑定 CUDA 训练保存退出和完整恢复重放。两次测试驱动
问题、对照组退化和同族评估限制均保留，未重置窗口或将失败改判通过。
发布前更新中英文首页、版本说明及机器可读验证摘要；远端四组原生 CI 与
最终下载包验证独立记录，不用本地测试替代。
