# EvoInquiry 1.5.0 实施计划

2026-10-18，用户已批准实施。基线为 `180f7d8ebd6690caa3a77328e9cb2bf5eeeee7ce`，
当前正式版及正式安装仍为 1.4.0。本分支开发 1.5.0，不将开发中的功能标为正式发布。

目标：在明确的研究问题、证据标准和资源边界内持续推进任务；记录真实操作与失败，
让已有经验参与后续决策，并用独立任务检验工具修改。有效负结果、合理转向和有依据的
停止均可完成研究任务；论文产出和正向指标不是共同的成功条件。

## Codex Plan / Goal 接入

Plan 用于规划与审阅，不在纯规划模式执行实验、修改代码或创建执行状态。
用户已批准并要求实施时继续实施，不重新要求批准同一个方案。

Goal 是可选的、属于线程的持续目标；只有用户明确要求设置或使用 Goal 时创建。
目标包含交付物、核验方式、允许的输入/操作、资源上限、停止条件及阻塞交接。
宿主未提供 Goal 时在当前授权任务内工作，持久材料继续保存在项目原记录中。
Goal 完成不代替科研审阅，宿主 token 预算不代替 GPU、时间、费用和存储预算。

官方依据（2026-10-18 已查阅）：
[Plan 与 Goal](https://developers.openai.com/blog/mastering-codex-remote-for-engineering)、
[Goals](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex)。
