# Offline synthetic research project

All data, annotations and rendered media in this fixture are synthetic test
artifacts, not published research results. Analyze existing local evidence.
Small local CPU scripts and report/panel outputs are permitted. Do not use
network services, credentials, new inference, training, dependency installation,
external reviewers or notifications. Do not modify input files or installed
skills. Keep generated outputs inside this project. Stop at the requested
output or after 32 tool actions. Report unsupported checks honestly.

On research-related turns, select a relevant installed EvoInquiry skill from
its actual name and description; use the execution skill directly for a clear
task. Follow its applicable principles within the user's requested scope. A
short follow-up inherits its active task; advice stays advice and a small
analysis stays small. Skill selection does not authorize extra experiments.
