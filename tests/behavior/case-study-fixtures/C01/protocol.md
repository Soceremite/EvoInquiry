# Classification evaluation

Held-out split demo-v1: all 12 IDs in predictions.csv, one frozen baseline and
candidate run. Each row is the same input for both methods. Primary metric:
accuracy (higher better), all 12 count equally. Label mapping is the literal
cat/dog/bird strings. There are no independent training repeats or confidence
values. The table contains the full available prediction pool. No image or
raw text inputs are supplied; labels/predictions support confusion diagnosis,
not an inspection of the original appearance. Use IDs to trace examples.
