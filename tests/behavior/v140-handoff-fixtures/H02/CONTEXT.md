# Cumulative quantities

This is an offline mathematical project with synthetic working notes. The
question is whether cumulative quantities can answer all contiguous range-sum
queries, and under what assumptions a resulting range sum is nonnegative.

Work over finite real sequences x[0], ..., x[n-1], including n=0. A range [l,r)
has integer endpoints with 0 <= l <= r <= n; an empty sum equals zero. There is
no training, dataset, literature service or external reviewer available. A
proof or counterexample is the relevant evidence; code checks alone are not a
proof of a statement about all finite real sequences.
