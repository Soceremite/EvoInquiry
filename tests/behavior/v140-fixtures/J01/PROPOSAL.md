# Synthetic bounded theory proposal
For a finite real sequence a_1,...,a_n with every a_i >= 0, inclusive prefix sums S_k=sum_{i=1}^k a_i are nondecreasing for k=1,...,n. Proof: S_{k+1}-S_k=a_{k+1}>=0. Claim is only monotonicity, not strict monotonicity, novelty, numerical stability or a runtime gain.
