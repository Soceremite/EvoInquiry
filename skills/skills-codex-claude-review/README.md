# Claude reviewer overlay

These files are optional compatibility resources for an explicit reviewer
configuration. The standard EvoInquiry plugin discovers `skills-codex`, so
placing this overlay in the repository does not enable it.

Configure the [review bridge](../../mcp-servers/claude-review/README.md)
before selecting this backend. The retained project-local installer supports
`--with-claude-review-overlay`; such an installation has a separate layout
and does not constitute validation of every EvoInquiry principle or workflow.
Use [the standard plugin route](../../README.md) for the documented beta setup.
