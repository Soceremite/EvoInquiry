# EvoInquiry 1.0 Beta 5 — candidate

Long experiments now include bounded artifact retention and storage peak planning. The default keeps the latest two valid full training recovery points, one validation-selected best model, and required final or dependent artifacts without unnecessary copies. The budget accounts for completed runs and complete new saves before old checkpoints rotate. Planning, implementation, launch, batch execution, and monitoring receive scoped guidance through 15 Codex extension hooks; all 84 entrypoints and 83 retained workflow bodies remain preserved.

An optional standard-library checkpoint helper supports custom local training loops with a caller-supplied writer and loader validator, atomic manifests, cooperative writer locking, file hashes, dependency pins, and preview-first cleanup. Failed saves preserve valid recovery points. This helper does not provide distributed or object-store transactions, model serialization, or automatic migration of unrelated files. Existing training programs must implement and verify the effective saving configuration before these defaults take effect.

Analysis-to-plan guidance keeps numerical caveats within ordinary analysis unless a formal claim verdict or existing workflow gate is required. Detailed roadmaps use shared settings and compact experiment tables, retain necessary decision criteria, and reserve time for checking and delivering their artifacts. Formal review and recovery gates remain intact.

The local Linux regression suite passed 825 tests with 20 environment-dependent skips. Storage checks include 600 save events spanning a simulated 300,000-step schedule, failure and ownership cases, concurrent inspection, and real PyTorch CPU interrupted-versus-continuous training with optimizer, scheduler, and random state recovery. The original 24-case behavior manifest remains frozen; additional storage cases are assessed separately. See [validation status](docs/BETA_VALIDATION.md) and [release-validation.json](release-validation.json) for actual behavior outcomes, package checks, and limitations. This candidate has not been published; public publication requires passing Linux and macOS CI suites.

Source archives built from the reviewed commit include SHA256SUMS and a manifest identifying their source and inventory. Installation uses the Codex plugin commands in README.md or README_CN.md. GPU training, distributed recovery, live providers, complete research pipelines, and broad discipline coverage have not been verified end to end.
